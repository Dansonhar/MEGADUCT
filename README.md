# MEGADUCT

Website project.

## Structure

```
assets/
  css/            stylesheets
  js/             scripts
  img/
    products/     product imagery
    site/         site chrome / branding
```

## Getting started

Clone and serve the directory with any static web server:

```bash
git clone https://github.com/Dansonhar/MEGADUCT.git
cd MEGADUCT
python3 -m http.server 8000
```

Then open http://localhost:8000
